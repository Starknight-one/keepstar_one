Pencil vs V4 Engine

Полное сравнение возможностей. Что есть, чего нет, что нам нужно. 2026-04-05

Pencil

Design Tool
Canvas-based, статический дизайн. 14 типов нод, flexbox, полная стилизация, компонентная система, 10 параметрических стилей, 8 design guides.

V4 Engine

Widget Engine
Ops-based, динамические виджеты. 6 типов атомов, layout tree, data binding, replication, navigation, actions. Заточен под e-commerce.
Ключевое отличие: Pencil рисует статичные экраны на canvas. V4 генерирует динамические виджеты привязанные к данным каталога — с навигацией, лайками, корзиной. Оба управляются через LLM.

Это самый большой gap. У Pencil полноценная компонентная система: создал кнопку → переиспользуй 100 раз с вариациями. У нас Agent2 генерирует ops с нуля каждый раз.

Решение: Named Ops Bundles

Аналог компонентов для LLM-driven движка. Вместо ref-instances — registry ops-бандлов по имени:

// Agent2 говорит:
{ "preset": "product_card" }          // вместо 9 ops каждый раз

// Или с кастомизацией:
{ "preset": "product_card",
  "ops": [                            // override поверх пресета
    {"op":"update","target":"price","props":{"textStyle":{"fontSize":"2xl"}}}
  ]}

// Или полностью с нуля:
{ "ops": [...9 ops...] }             // freestyle, когда пресет не подходит
  • Экономит ~400 output токенов на каждый вызов (= $0.002 на запрос)
  • Consistency: одинаковые карточки выглядят одинаково
  • Agent2 вызывает по имени ИЛИ пишет ops ИЛИ комбинирует
  • Легко добавлять новые: product_detail, comparison_row, hero_banner

Второй критический gap. У Pencil design-знания формализованы в guides: когда grid, когда list, правила spacing, hierarchy. У нас это только неформальные инструкции в промпте Agent2.

Решение

  • Guides = загружаемые документы в промпт Agent2 (по аналогии с get_guidelines)
  • Вызываются по ситуации: каталог → "product grid guide", детальная → "detail view guide"
  • Не постоянно в промпте (экономия токенов), а подгружаются когда нужны
  • Формализуют: spacing rules, when grid vs list, hierarchy principles

Что нужно закрыть
▾

Tier 1 — Нужно для "генерить любой фронт"

#1 Named Ops Bundles

Registry ops-бандлов по имени. Agent2 вызывает "product_card" вместо 9 ops. Экономит токены, даёт consistency.

#2 Design Guides

Формализованные правила дизайна (spacing, hierarchy, when grid vs list). Загружаются в промпт по ситуации.

#3 text-align

Центрирование текста в блоках. Нет прямого свойства, нужно добавить в TextStyle.

Our Advantages over Pencil
Что есть у нас и нет у Pencil
▾

Data Binding

fieldName → автоматически подставляет данные из каталога. У Pencil всё статичное.

Replication

1 шаблон → N виджетов за 0 токенов. Pencil копирует руками.

Navigation

Instant expand (detail), back, history. Pencil — статичные экраны.

Actions

Like, cart, compare прямо на виджетах. Pencil — нет интерактивности.

Wildcard Ops

"Измени price во ВСЕХ виджетах" одной операцией. У Pencil нет аналога.

Constraints

Автоматическая нормализация: consistency across N виджетов. Pencil — каждый вручную.
