# Launch Checklist — План по завершению и выходу на продажи

Цель: **10+ LoI за 2 недели**

---

## Product Quality

- [ ] Составить и проверить E2E тесты пользовательские
- [ ] Проверить что можно использовать любую информацию (не только cosmetics)
- [ ] Проверить что можно строить любой фронт и это выглядит ок
- [ ] Доработать страницы пролайканных товаров и корзину
- [ ] Доработать локальные фильтры и сортировки (не всегда проще писать в чат, порой проще просто ткнуть пару кнопок)
- [ ] Проверить качество работы поиска, если есть возможность прокачать — прокачать
- [ ] Проверить что можно запустить два чата для одного тенанта параллельно
- [ ] Проверить что можно запускать несколько чатов по разным тенантам параллельно
- [ ] Доработать админку, в частности загрузку информации
- [ ] Попробовать добавить ответы через LLM текстом в том числе
- [ ] Проверить качество кода, кол-во мёртвого кода

## Marketing & Sales

- [ ] Собрать лендинг, транслировать ценность и давить на боль
- [ ] Записать демо ролик который продаёт
- [ ] Составить план продаж, портрет покупателя: кто точно прям купит, кому прям супер нужно прямо сейчас
- [ ] Соообразить ценообразование: как и за сколько продавать
- [ ] Понять и попробовать вставить маркетинговые триггеры

## Infrastructure & Ops

- [ ] Сделать отдельный дев стенд
- [ ] Вычистить продовый гит, чтобы там был только чисто прод и ничего более
- [ ] Проверить безопасность и может GDPR, так как на зарубеж всё
- [ ] Покрыть проект мониторингами и алертами на проде (часть для меня, часть для тенантов чтобы они тоже понимали что происходит)
- [ ] Поставить рейт лимит защиту чтобы не сожгли все API
- [ ] Страницы 404, "API антропика недоступно" и всё такое
- [ ] Миграции и версионирование БД

## Testing & Reliability

- [ ] Трекинг ошибок (Sentry или аналог)
- [ ] Нагрузочное тестирование
