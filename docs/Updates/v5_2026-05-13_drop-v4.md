## Context

V5 (`project_v5/`) has been the production chat engine for weeks
(deployed at `v5-engine-production.up.railway.app`, scene-graph
architecture, own catalog read path, own widget frontend). V4
(`project_v4/`) and the V4 widget (`project/`) were still in the
