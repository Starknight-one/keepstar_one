## Approach

`master_cosmetics` table AND the 17 legacy `master_products` columns into `master_products.tier2`
(jsonb), keyed by `master_field_definitions`. Same `tier2 = COALESCE(tier2,'{}') || patch`
merge pattern as the existing tier3 path. Curator's per-field router gains a `tier2.<key>`
branch (scalar fill-when-empty + jsonb array set-union), mirroring `tier3.<key>`.
