## Hybrid Engine: 3 modes (Auto / Ops / Build)

The visual_assembly tool now supports 3 execution modes, making the rendering pipeline significantly more capable.

### Auto Mode (existing, enhanced)
- Full V2 Engine pipeline rebuild from data + preset
- **Snapshot Carry-Over**: locked atom customizations (textStyle, wrapper, format) and freestyle atoms survive auto rebuilds
- **Formation-level snapshot**: grid columns, rows, mode, widget size now also preserved across rebuilds
- **StampTreeIDs**: every atom and layout node gets a readable ID (e.g. `a-s0-w0-price`, `n-s0-w0-root`)
- **Compact formation_tree**: Agent2 sees 1 widget template + count instead of all 50 widgets (token savings)

### Ops Mode (new)
Patch existing formation without rebuild. 4 operations:
- **update** — merge props into atom/node/widget/formation by field name
- **delete** — remove atom or layout node
- **insert** — add freestyle atoms (buttons, badges) or data-bound fields
- **move** — relocate atom/node to different parent

Key features:
- **Wildcard expansion**: `target:"price"` applies to all widgets automatically
- **Dedup guard**: prevents double-insert when wildcard overlaps specific IDs
- **Formation-level ops**: `target:"formation"` for columns, rows, mode changes
- **Ref chaining**: `ref:"cta"` + `parent:"$cta"` for multi-op sequences
- **Data binding**: inserted atoms with `fieldName` auto-resolve values from entity data
- **Auto-lock**: all ops-modified atoms get `rigidity: locked`

### Build Mode (new)
Multi-section page composition for landing pages, hero+grid layouts:
- **Auto sections**: full V2 pipeline with data
- **Freestyle sections**: literal atoms with textStyle, wrapper, layout
- **Template fix**: freestyle widgets now get `Template: "GenericCard"` for proper V2 rendering

## Frontend UX Fixes

### Card click vs text selection
- Cards no longer open on text selection or drag
- Mouse movement detection (>5px threshold) prevents accidental navigation
- `window.getSelection()` check skips navigation when text is selected

### Add to Cart button redesign
- **Default**: clean `+` icon with circular black outline (32px)
- **In cart**: filled black circle showing quantity number
- **Click quantity**: expands into inline stepper `[−] N [+]`
- **Auto-collapse**: stepper hides after 2.5s of no interaction
- **Decrement to 0**: removes from cart, reverts to plus icon

### Action Toolbar
- Like/Cart sidebar buttons verified working with CartView and LikedView
- Full state management: localStorage persistence (24h TTL) + backend sync
