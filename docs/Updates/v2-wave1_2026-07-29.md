## What shipped

**B1 — critical path (handoff tails 1/3/4):**
- `EnsureZeroInputStep`: rendering a `surface_links` block auto-stages +
  auto-applies `issue_surface_urls` server-side (owner law: user-visible
  artifacts never depend on the model having called a tool). Guarded: only
  fires when every other step is terminal; synthetic sets reach the DATA
  zone via `operations.NewSyntheticSetPublisher` injected into the applier.
- surface_links binding: real root cause was `replicate` argument
  resolution in compose_turn (NOT preset field keys — the brief's guess was
  wrong); `SystemPresetReplicateSource` now covers surface_links /
  manifest_summary / operation_card. URL node got `wrapper:"link"`
  (v5 seed; admin's mirrored copy NOT updated — see gaps).
- adopt_presets stage-time sanitize: unknown names stripped + named with
  candidates on the OK summary; rejects only when nothing valid remains.

**B2+B3 — canvas shell + staged reveal (frontend):**
- Canvas tabs: Builder always; Storefront/CRM appear when URLs are issued
  (live iframes of the real surfaces). Sources merge block-derived +
  manifest URLs in a session-sticky ref (tabs never vanish on next turn).
- Chat is a floating dock over the full-stage canvas (birthDesktop
  pattern); history collapses upward, translucent. `layout:'split'` →
  `'canvas'`, SplitMessageView.jsx deleted.
- Per-block SSE frames render onto the canvas as they arrive with the
  realEstateBirth stagger (spring y+scale; honest stream, no fake delays);
  thinking indicator until first block.
- Version footer `v2.0` (single VERSION constant).

**B4 — realty demo seed pack (L6):**
- New zero-input manifest step `seed_demo_data`: 12 listings (4 groups
  with units), namespaced SKUs `KS-DEMO-REALTY-…` (admin matches masters
  on bare LOWER(sku) globally — un-namespaced demo SKUs would capture the
  next tenant's real upload), 7 leads (E.164, statuses from the realtor
  bundle), contacts; all flagged demo. Listings go through the same admin
  import door as real uploads; leads/contacts via EntityPort. Idempotent.
- Guards: refuses to seed when a real import is on the session; a pending
  seed step is stood down the moment a real upload arrives; skipped counts
  as done for issue_surface_urls (never gates handover).
