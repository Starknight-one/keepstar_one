## Context

After chunks 9–11 closed the entire P0 surface (tool shapes, frontend
renderer, interaction loop), Vlad opened V5 widget locally and reported
«тот ещё пиздец, скорее всего пресеты херовые». Three turns surfaced
**four overlapping render-quality gaps** logged in `docs/v5-known-gaps.md`
under «Render-quality gaps surfaced by first manual test (2026-05-03)»:

1. **Стек ≠ сетка**: replicate fan-out клонирует card-frame в Document
   root; SceneGraphRenderer стекает их `flex-direction: column`. Frame.jsx
   не знает `layout.wrap`. Pencil/v9 это умеет — мы недотащили рендер.
2. **priceFormatted ломается** (исходный диагноз): `binding_to_map.go`
   пишет ключ только если `PriceFormatted` non-empty. **Опровергнуто
   пред-исполнительной разведкой**: `postgres_catalog.go:268, 289`
   уже зовёт `formatPrice` на каждом продукте при чтении. Часть была
   исключена из плана. Проблема «только названия» из manual test
   объясняется stack-overflow без grid (длинные описания съедали
   карточки), что закрывается фиксом #1.
3. **Нет width/maxWidth на frames**: V9 умеет (`value_position.go`
   парсит `Sizing`), но Frame.jsx не читал.
4. **Modify-bias**: V4 имел REQUIRED `mode: rebuild|modify` enum, V5
   потерял в чанке 9. Без явного mode V5 идёт в modify когда есть
   `state.Current.Template`, даже на ask-ах вроде «сделай лендинг».

После предпланового исследования + 4-х вопросов Vlad'а к каждому гэпу
все четыре зашиты в один когерентный чанк (по отдельности любой даст
сломанный визуал).

## Approach

### Backend — mode parameter (Q4)

`internal/tools/tool_visual_assembly.go`:
- Добавлен **REQUIRED** `mode: enum["rebuild", "modify"]` в JSON-Schema
  visual_assembly. Description содержит decision rules для LLM.
- Execute явно ветвится на mode:
  - `rebuild + preset` → load preset + components → Materialise (как
    раньше)
  - `rebuild + ops only` → `engine.NewDocument()` (freestyle / compose)
  - `modify + ops` → load `state.Current.Template`. Если пустой →
    IsError «modify requires a current Document; pick rebuild for the
    first turn»
- Mode missing → IsError «mode required: must be \"rebuild\" or
  \"modify\"».

### Backend — card seeds get grid wrapper + width (Q1, Q3)

Каждая `product_card*` обёрнута в `grid`-frame с
`layout: {direction:"row", wrap:true, gap:"md", justify:"start"}`.
Сами card-frame получили `width` (px):
- `product_card`: 280
- `product_card_compact`: 200
- `product_card_horizontal`: 540
- `product_card_list_row`: column-stack wrapper, без card width
  (full-row natural)

`product_detail` / `product_detail_horizontal` получили `maxWidth` на
root детали (720 / 960) — single-instance views не нужны grid wrapper.

### Frontend — Frame.jsx + CSS (Q1 + Q3)

`project_v5/frontend/src/renderer/nodes/Frame.jsx`:
- Читает `layout.wrap` → `data-wrap="true"` атрибут.
- Читает `node.width / minWidth / maxWidth` → inline `style`. Number →
  `<n>px`, string → pass-through (поддерживает `"50%"`, `"100vw"`).
- Helper `sizeValue(v)` нормализует значения; `sizingStyle(node)`
  возвращает объединённый style.

`project_v5/frontend/src/widget.css`:
- `.kw-frame[data-wrap='true'] { flex-wrap: wrap; }`
- `.kw-frame[data-justify='start']` + `[data-justify='end']`
- `.kw-display-inner { align-items: flex-start; }` чтобы grid wrapper
  не растягивался по высоте контейнера.

### Backend — Agent2 prompt (Q4)

`internal/prompts/agent2_prompt.go`:
- Новая секция `## MODE — REQUIRED, pick one every turn` с явными
  правилами и фразой «когда мог бы сказать ‹оставь что есть, но …›
  → modify; ‹покажи / сделай / render / show me› → rebuild». Цитирует
  V4 `prompt_compose_widgets.go:13-99`.
- DECISION RULES rule 1 переписан — лидирует с «ALWAYS pass mode».
- Все примеры в BUILDING / MODIFYING / COMPOSING / DETAIL обновлены —
  каждый `visual_assembly({...})` теперь содержит mode.

  не меняются визуально после клика. P2.

  портирован. Width/maxWidth закрывает все текущие случаи.
- **Real V9 `Sizing` (Fixed/Fill/Fit)** — out of scope. Width/maxWidth
  как numbers/strings достаточно.

  «modify requires a current Document»; LLM должен флипнуть на

  prompt может потребовать reinforcement.
- **`docs/v5-known-gaps.md` price-fallback row** — изначально в плане
  чанка-12 был server-side formatter в ProductToMap. Pre-execution
  разведка показала что `postgres_catalog.go:268` уже зовёт formatPrice
  на чтении — фикс не нужен; row в gaps оставлен для истории.
