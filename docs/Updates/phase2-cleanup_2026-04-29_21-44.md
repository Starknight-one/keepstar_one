## Known gaps / caveats

### 🔴 Pre-push gate — Railway Chat (03131b3d)

**Push в main заблокирован** до проверки Railway → Chat сервис → Settings → Source → rootDirectory.
- Если `rootDirectory = project/backend` — этот сервис деплоит снесённый каталог. После push в main следующий триггер деплоя упадёт. Нужно либо переключить сервис на `project_v4/backend`, либо удалить сервис.
- Если `rootDirectory ≠ project/backend` — push безопасен.

Также параллельная сессия упомянула, что Railway сейчас «лежит / в очереди»: push отложен до зелёного света от параллельной сессии независимо от Chat-сервиса.
